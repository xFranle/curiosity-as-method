# Curiosity as Method / La curiosidad como método

Personal bilingual blog (English and Spanish) by Franle: [franle.blog](https://franle.blog).

Built with [Astro](https://astro.build), React, Tailwind CSS and [Pagefind](https://pagefind.app),
on top of the open-source [Growing Galaxy](https://github.com/OwenCedaric/GrowingGalaxy) theme.

## Run locally

Requires Node 22.22+ and [pnpm](https://pnpm.io) 11.

```bash
pnpm install
pnpm dev            # http://localhost:4321
pnpm run build      # static site in dist/
```
